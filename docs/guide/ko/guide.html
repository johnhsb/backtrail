화면은 테스트용 가상 머신에서 찍은 것이라 드라이브 이름(VMware Virtual …)이 실제 컴퓨터와 다릅니다.

1. Backtrail이란?

Backtrail은 USB 메모리로 부팅해서 컴퓨터의 디스크를 이미지 파일로 저장(백업)하고, 문제가 생기면 그 이미지로 디스크를 그대로 되돌리는(복원) 프로그램입니다.

  • Windows, Linux 등 어떤 운영체제든 디스크 단위로 백업합니다. 운영체제가 망가져 부팅되지 않는 컴퓨터에서도 쓸 수 있습니다.
  • 새로 산 빈 디스크에도 복원할 수 있어서, 디스크 고장·랜섬웨어·실수로 지운 파일에서 빠르게 회복할 수 있습니다.
  • 사용 중인 공간만 저장하므로 이미지가 디스크 전체 크기보다 훨씬 작습니다.
  • Redo Rescue로 만든 백업(.redo)도 그대로 복원할 수 있습니다.

준비물

준비물설명
USB 메모리 (2 GB 이상)Backtrail을 넣어 부팅에 쓸 USB입니다. 안의 내용은 모두 지워집니다.
백업을 저장할 곳외장 하드디스크나 큰 USB 메모리, 또는 네트워크 공유 폴더(NAS 등). 백업할 디스크의 사용 중인 용량보다 여유 공간이 커야 합니다.
다른 컴퓨터 한 대Backtrail 파일(ISO)을 내려받아 USB에 기록할 때만 필요합니다.
꼭 알아 두세요 백업 이미지는 원래 백업한 그 컴퓨터에 복원하는 용도입니다. 하드웨어가 다른 컴퓨터에 복원하면 운영체제가 부팅되지 않을 수 있습니다. 컴퓨터 구성을 바꿨다면 새로 백업해 두세요.

2. 부팅 USB 만들기

1
ISO 파일 내려받기 github.com/johnhsb/backtrail 의 Releases에서 backtrail-5.0.1.iso와 SHA256SUMS를 내려받습니다.
2
(선택) 파일이 온전한지 확인 macOS·Linux 터미널에서 sha256sum -c SHA256SUMS --ignore-missing 를 실행해 OK가 나오면 정상입니다.
3
USB에 기록 balenaEtcher(Windows·macOS·Linux)나 Rufus(Windows)를 열고, ISO 파일과 USB 메모리를 고른 뒤 기록(Flash/시작)을 누릅니다. 파일을 USB에 그냥 복사하면 부팅되지 않습니다.

3. USB로 컴퓨터 시작하기

1
USB를 꽂고 컴퓨터를 켭니다 켜자마자 부팅 메뉴 키를 여러 번 누릅니다. 제조사마다 달라서 보통 F12, F11, F9, F8, Esc 중 하나입니다.
2
목록에서 USB 메모리를 고릅니다 UEFI 보안 부팅(Secure Boot)을 켠 상태로도 부팅됩니다. 끌 필요가 없습니다.
3
Backtrail 부팅 메뉴가 나타납니다 첫 항목이 선택된 상태로 잠시 기다리면 자동으로 시작합니다. 64비트·32비트 중 컴퓨터에 맞는 쪽이 자동으로 선택됩니다. 화면이 깨지거나 검게 나오면 다시 켜서 Safe video mode를 고르세요.
Backtrail 부팅 메뉴. 아래 원 안의 숫자가 0이 되면 자동으로 시작합니다.
4
첫 화면에서 할 일을 고릅니다 데스크톱이 뜨면 Backtrail 앱이 자동으로 열립니다. 백업, 검증, 복원 중 하나를 누르세요. 아래에는 이 컴퓨터에서 찾은 드라이브가 보입니다.
첫 화면. 실제로 무언가를 바꾸기 전에는 디스크의 어떤 것도 바뀌지 않습니다.

4. 백업하기

첫 화면에서 백업을 누르면 다섯 단계로 진행합니다. 화면 위쪽에 지금 몇 단계인지 표시됩니다.

1
원본: 백업할 드라이브 선택 백업할 디스크(보통 Windows가 설치된 디스크)를 고르고 다음을 누릅니다.
2
파티션: 저장할 파티션 선택 기본으로 모든 파티션이 선택되어 있으니 그대로 두면 됩니다. 오른쪽에 선택한 크기가 보입니다. 파티션 테이블과 부트 레코드는 항상 함께 저장됩니다.
3
저장 위치: 백업을 저장할 곳 선택 이 컴퓨터 탭에서 외장 디스크를 고르거나, 네트워크 드라이브(Windows 공유 폴더·NAS), NFS, SSH 탭에서 네트워크 위치를 입력합니다. 백업하려고 고른 파티션은 저장 위치 목록에 나오지 않습니다.
네트워크로 저장할 때보안상 SSH가 가장 안전합니다(전송이 암호화됨). NFS는 암호화와 인증이 없으니 믿을 수 있는 네트워크에서만 쓰세요.
4
폴더: 저장할 폴더 선택 고른 드라이브의 여유 공간이 표시됩니다. 선택을 눌러 폴더를 고르거나, 그대로 두면 드라이브의 맨 위 폴더(/)에 저장합니다.
5
이름: 백업 이름 정하고 시작 기본 이름은 오늘 날짜입니다. 영문자, 숫자, -, _만 쓸 수 있습니다. 메모에 무엇을 왜 백업했는지 적어 두면 나중에 찾기 쉽습니다. 백업 시작을 누르면 시작합니다.

백업하는 동안

  • 진행률(%), 걸린 시간, 남은 시간, 속도가 표시됩니다. 시간은 사용 중인 용량에 비례합니다.
  • 상세 로그를 펼치면 자세한 진행 기록을 볼 수 있고, 클립보드로 복사할 수 있습니다.
  • 끝날 때까지 화면을 그대로 두세요. 필요하면 취소할 수 있습니다.

저장 위치에는 이름.redo 파일 하나와 파티션별 .img 파일들이 생깁니다. 모두 한 폴더에 함께 보관하세요.

백업이 끝나면바로 다음 장의 검증을 한 번 실행해 두면, 나중에 복원할 때 이미지가 온전하다는 것을 미리 확인할 수 있습니다.

5. 백업 검증하기

검증은 백업 이미지에 오류가 없는지 확인합니다. 디스크에 아무것도 쓰지 않는 읽기 전용 작업이라 안심하고 실행해도 됩니다.

단계화면할 일
1백업 이미지는 어디에 있나요?백업을 저장한 드라이브나 네트워크 위치를 고릅니다.
2백업 이미지 선택검증할 .redo 파일을 고릅니다.
3검증할 파티션 선택파티션을 고르고 검증 시작을 누릅니다.

원시(raw) 모드로 저장한 파티션은 복원은 되지만 검증은 할 수 없습니다.

6. 복원하기

복원은 대상 드라이브를 덮어씁니다복원할 드라이브에 있던 내용은 지워지고 백업한 시점의 내용으로 바뀝니다. 드라이브를 잘못 고르지 않도록, 드라이브 이름과 크기를 꼭 확인하세요. 중요한 자료가 남아 있다면 먼저 따로 복사해 두세요.
단계화면할 일
1백업 이미지는 어디에 있나요?백업을 저장한 드라이브나 네트워크 위치를 고릅니다.
2백업 이미지 선택복원할 .redo 파일을 고릅니다. 이미지 정보(날짜, 메모, 파티션)가 표시됩니다.
3복원할 드라이브 선택이미지를 쓸 디스크를 고릅니다. 원래 디스크보다 작으면 경고가 나옵니다.
4복원할 항목 선택 전체 시스템 복구: 디스크 전체를 백업 당시 그대로 되돌립니다. 새 디스크로 교체했을 때나 컴퓨터를 통째로 되돌릴 때 고릅니다.
데이터만 복원: 지금의 파티션 구성은 그대로 두고, 고른 파티션에만 데이터를 씁니다.
확인한 뒤 빨간 복원 버튼을 누르고, 마지막 확인 창에서 한 번 더 확인합니다.

복원이 끝나면 USB를 빼고 컴퓨터를 다시 켜면 백업한 시점의 상태로 시작합니다. 대상 디스크가 원래보다 크면, 남는 공간은 시작 메뉴의 GParted로 파티션을 늘려 쓸 수 있습니다.

7. 원격 지원 받기 · 언어 바꾸기 · 끄기

원격 지원 받기

멀리 있는 사람에게 도움을 받으려면 화면 오른쪽 위의 원격 지원 허용을 누릅니다. 그러면 주소와 비밀번호가 표시되고, 도와줄 사람은 VNC 뷰어로 이 주소에 접속해 화면을 보고 조작할 수 있습니다.

도움이 끝나면 비밀번호 옆의 ×를 눌러 끕니다. 누를 때마다 새 비밀번호가 만들어집니다.

언어 바꾸기

오른쪽 위의 언어 메뉴(국기)에서 고릅니다. 한국어, 영어, 일본어, 중국어, 스페인어, 독일어, 프랑스어, 포르투갈어를 지원합니다. 옆의 달 모양 버튼은 어두운 화면(다크 모드)으로 바꿉니다.

끄기

화면 왼쪽 아래 작업 표시줄의 빨간 전원 버튼을 눌러 끄거나 다시 시작합니다. 꺼진 뒤 USB를 빼세요. Backtrail은 USB에서만 실행되어서, 끄면 작업 중에 만든 설정은 남지 않습니다(백업 파일은 저장 위치에 남습니다).

8. 자주 묻는 질문

디스크나 USB가 목록에 보이지 않아요.
Backtrail을 시작한 뒤에 연결했다면, 첫 화면으로 돌아갔다가 다시 들어가면 드라이브를 새로 찾습니다.
"이 드라이브에는 백업할 파티션이 없습니다"라고 나와요.
비어 있는 디스크를 골랐습니다. 이전 단계로 돌아가 데이터가 있는 디스크를 고르세요.
"저장할 수 있는 로컬 파티션이 없습니다"라고 나와요.
백업을 저장할 외장 디스크나 USB를 연결하세요. 새 디스크라면 시작 메뉴의 GParted로 파티션을 만든 뒤, 이전 단계로 돌아갔다가 다시 오면 목록에 나타납니다.
백업 파일이 너무 커요. 디스크 전체 크기만큼 필요한가요?
아닙니다. 대부분의 파일 시스템(Windows의 NTFS, Linux의 ext4 등)은 사용 중인 공간만 저장하고 압축까지 합니다. 일부 특수한 파일 시스템만 파티션 전체를 저장합니다(화면에 안내 아이콘이 표시됨).
다른 컴퓨터에 복원했더니 부팅되지 않아요.
하드웨어가 다른 컴퓨터에 복원하면 운영체제가 부팅되지 않을 수 있습니다. 이것은 백업 프로그램의 문제가 아니라 시스템 구성이 달라졌기 때문입니다. 원래 컴퓨터에 복원하는 것이 원칙입니다.
인터넷에서 드라이버나 설명서를 찾고 싶어요.
작업 표시줄의 지구본 아이콘으로 웹 브라우저를 열 수 있습니다. 내려받은 파일은 Downloads 폴더에 저장됩니다.
비밀번호를 물어봐요.
Backtrail은 자동으로 로그인합니다. 데스크톱을 로그아웃해서 로그인 창이 나오면 사용자 root, 비밀번호 redo를 입력하세요. SSH 원격 접속을 켜면(/root/enable-ssh) 새 비밀번호가 만들어져 화면에 표시되고, 그때부터는 그 비밀번호를 씁니다.
백업 이미지는 안전한가요?
백업 이미지에는 디스크의 모든 내용이 들어 있고, 이미지 자체는 암호화되지 않습니다. 다른 사람이 열어 볼 수 없는 곳(내 외장 디스크, 접근이 제한된 공유 폴더)에 보관하세요.
